## 👋 A little about me

I'm a **Full Stack Engineer | AI / ML Engineer** who enjoys turning complex ideas into reliable, usable products. My work spans **LLM applications, retrieval-augmented generation (RAG), AI engineering workflows, backend architecture, and modern web experiences**.

I started with **UI/UX and frontend engineering**, then moved deeper into full-stack development and applied AI. That combination shapes how I build: from the system architecture and data pipelines to the final interaction on screen.

- 🧠 Building a **self-hosted, privacy-first enterprise AI assistant** using RAG, pgvector, and vLLM, designed to support **1,000+ employees**.
- 🚀 Independently shipped **Astrynox ERP**, a live multi-tenant SaaS platform with an AI-powered financial assistant.
- 🛡️ Contributed to **ArgusV**, a computer-vision security platform built with YOLOv8 and GPT-4o.
- 💼 **Associate AI / UX Engineer** at **Asia Asset Finance PLC**.
- 🎓 **BSc (Hons) Computer Science**, University of Westminster (IIT) — specializing in AI & ML.

### 🧾 Astrynox ERP · Multi-tenant SaaS

`FastAPI` `Next.js` `PostgreSQL` `OpenAI` `Docker`

**Role:** Team contributor &nbsp;·&nbsp; **Context:** University group project

A computer-vision security platform combining real-time video, object detection and tracking, and LLM-assisted workflows. My contributions focused on the **live-streaming pipeline and detection flow**.

`FastAPI` `YOLOv8` `ByteTrack` `GPT-4o` `pgvector` `MediaMTX`

A privacy-first enterprise assistant architecture combining **multimodal RAG**, embeddings, hybrid retrieval with reciprocal rank fusion (RRF), caching, and LLM integration.

`BGE-M3` `pgvector` `RRF` `Redis` `vLLM` `GPT-4o Vision`
